# LIAL – Lineare Algebra

Vorgehen pro Aufgabe: zuerst von Hand rechnen, dann im Notebook mit NumPy kontrollieren.
Ein Notebook pro Thema: `notebooks/NN_thema.ipynb`.

| Nr. | Thema |
|-----|-------|
| 01 | Vektoren, Matrizen, Gleichungssysteme, Skalarprodukt |
| 02 | Gauss-Elimination |
| 03 | LR-Zerlegung |
| 04 | Inverse, Gauss-Jordan, Vektorprodukt, Determinante |
| 05 | Lineare Abbildungen |
| 06 | Einfache lineare Regression |
| 07 | Multiple lineare Regression |
| 08 | Eigenwerte und Eigenvektoren |
| 09 | Diagonalisierung, Spektralsatz |

Zum Verständnis: 3Blue1Brown, „Essence of Linear Algebra“. Zum Üben: Khan Academy.
